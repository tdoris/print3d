Wing files : Aile1, Aile2

'flat' version means without dihedral, like original balsa's Crobe.

About 'Light' version
----------------------
Allow less weight and save ~3/4g on each wing for a final
result around 24g for each wing.

Print settings for 'Light versions :
- layer weight   : 0.12mm
- line/wall thickness : 0.3mm
